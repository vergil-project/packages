
# Release 1.1.1 (2026-10-07)

## Bug fixes

- **restore secrets: inherit so environment secrets reach the reusable workflows (#7)**
* fix(packages): restore secrets: inherit so environment secrets reach the reusable workflows (#6)

With an explicit secrets map, cd-release's package-sign job saw an empty PACKAGE_SIGNING_KEY from its package-signing environment in three CD runs, although the environment was applied and holds verified key material. Hypothesis (GitHub's docs are silent): environment secrets reach a job in a cross-repo reusable workflow only when the caller passes secrets: inherit. Restore inherit on both callers with a scoped inline nosemgrep, justified in comments; the callees are first-party (same org).


## Features

- **keyring product and index configuration (#3)**
* feat(packages): keyring product and index configuration (#1)

Add the vergil-archive-keyring [package] (staged, noarch), packages.toml, the public key from vergil-project/vergil-tooling#3073, the nFPM overlay with postinst/postrm and vergil.repo, the ci package gate, cd secrets: inherit, and the publish-index workflow.

The dnf repo keeps el$releasever: $releasever_major is substituted only from RHEL 9.7 (libdnf 0.69.0-17), so it would break unpinned 9.0-9.6 hosts. Minor-pinned hosts are documented as unsupported, with a config(noreplace) edit as the workaround.
