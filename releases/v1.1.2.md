
# Release 1.1.2 (2026-11-15)

## Bug fixes

- **check packages.toml with vrg-package index --check-config (#26)**
Add scripts/bin/validate-custom, run by vrg-validate as its custom stage, so an invalid packages.toml fails validation locally instead of only at publish. Ref vergil-project/packages#22

- **keep the last two releases per line so a cached index never names a deleted file (#56)**
A release deleted the previous release's packages from the pool at once, while clients kept reading the index GitHub Pages had cached for up to ten minutes, so apt-get failed with a 404 on the file that index named. Keeping two releases per line leaves that file in place. Measured from the release assets, the site is about 482 MB at keep = 2, under vrg-package index's 750 MB warning and 900 MB limit.


## CI

- **stop passing container-tag to cd-release (#20)**
cd-release derives its container tag from the resolver since vergil-actions v2.1.52 (vergil-project/vergil-actions#1017); the input is ignored with a deprecation warning and will be deleted (vergil-project/vergil-actions#1019). This repo resolves to latest, the value it passed, so the release image is unchanged. Ref #18

- **move the daily ops cron to the 01:xx UTC hour (#53)**
GitHub schedule events are firing 7 to 9 hours late, landing the nightly run in the US Eastern working morning. Moving the cron five hours earlier keeps it overnight despite the lag. The minute (the per-repo stagger) is unchanged. Ref vergil-project/packages#52.
