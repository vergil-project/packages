
# Release 1.1.0 (2026-10-06)

> **Not published.** 1.1.0 was never tagged or released: its `package-sign`
> job could not read the signing key (#6). These changes ship in 1.1.1.

## Features

- **keyring product and index configuration (#3)**
* feat(packages): keyring product and index configuration (#1)

Add the vergil-archive-keyring [package] (staged, noarch), packages.toml, the public key from vergil-project/vergil-tooling#3073, the nFPM overlay with postinst/postrm and vergil.repo, the ci package gate, cd secrets: inherit, and the publish-index workflow.

The dnf repo keeps el$releasever: $releasever_major is substituted only from RHEL 9.7 (libdnf 0.69.0-17), so it would break unpinned 9.0-9.6 hosts. Minor-pinned hosts are documented as unsupported, with a config(noreplace) edit as the workaround.
